## Sobre mim

Sou desenvolvedor Full Stack com foco em criar soluções web úteis, organizadas e fáceis de evoluir.
No dia a dia trabalho com **Python**, **Django**, **FastAPI**, **Java**, **React**, **SQL Server**, **PostgreSQL**, **MySQL**, **Docker** e ferramentas de dados como **Power BI**.

Gosto de participar do ciclo inteiro: entender a dor, modelar a solução, construir a API, cuidar do banco, entregar uma interface limpa e deixar o projeto pronto para rodar com segurança.

```txt
backend        Python, Django, FastAPI, Java, Quarkus
frontend       React, TypeScript, JavaScript, HTML, CSS
database       SQL Server, PostgreSQL, MySQL, SQLite
devops         Docker, Docker Compose, Git, CI/CD
data           Power BI, pandas, openpyxl, dashboards e relatórios
cloud          Azure, AWS, integrações e serviços externos
```

Tenho trabalhado em projetos com perfis diferentes, o que me ajuda a pensar tanto em produto quanto em sustentação:

- sistemas Django para fluxos internos, autenticação, templates e integrações;

- frontends React/Vite com TypeScript, componentes reutilizáveis e testes;

## Meu jeito de construir

```txt
1. Entendo a regra antes de escrever código.
2. Prefiro soluções simples, rastreáveis e fáceis de manter.
3. Valido com teste, execução local ou revisão objetiva do impacto.
4. Documento o suficiente para a próxima pessoa não precisar adivinhar.
5. Cuido da experiência de quem usa e de quem mantém.
```
